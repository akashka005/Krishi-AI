# 🌱 KRISHI AI: Earth & Silicon

**KRISHI AI** is a premium, SaaS-grade agricultural intelligence platform designed to bridge the gap between organic farming and state-of-the-art technology. Built with a bespoke "Earth & Silicon" design language, it offers farmers a living, breathing dashboard for real-time crop management and AI-driven insights.

---

## ✨ Features

### 📡 Agricultural HUD
- **Real-time Weather**: Live telemetry (Temp, Humidity, Wind, Rain) based on browser geolocation.
- **Dynamic "Wind-Sway" UI**: Background animations and neural elements that respond to local wind speeds.

### 🧠 Neural Engine
- **Voice Waveform HUD**: An animated, high-fidelity waveform for voice-activated farming queries.
- **Disease Detection**: A simulated AI vision scan for leaf-level disease diagnosis and treatment protocols.
- **Smart Suggestions**: Context-aware recommendations for irrigation, crop rotation, and soil health.

### 🎨 Premium UI/UX
- **Earth & Silicon Design**: A fusion of organic textures (glassmorphism) and high-tech neural visualizations.
- **Animated Favicon**: A pulsing, growing sprout in the browser tab to match the app's life cycle.
- **Full Chat Management**: Rename, delete, and manage conversations with a sleek, interactive sidebar.

---

## 🛠️ Tech Stack

- **Frontend**: React, Vite, Tailwind CSS v4, Framer Motion, Lucide Icons.
- **Backend**: FastAPI (Python), SQLAlchemy, SQLite.
- **AI**: Groq Cloud API (Llama 3 / Mixtral) for ultra-low latency inference.

---

## 🚀 Getting Started

### Prerequisites
- Python 3.10+
- Node.js 18+

### 1. Backend Setup
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
